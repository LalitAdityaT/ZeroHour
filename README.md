# ZeroHour

ZeroHour is an Unreal Engine 5.4 multiplayer shooter project.

## Repository contents

This repository contains the project source and configuration only. Unreal content assets, including maps, UI assets, and marketplace-style packs, are intentionally excluded. As a result, this checkout is not a complete playable project and may require the original assets to build or run fully.

Generated build files, editor data, and packaged game outputs are also excluded.

## Opening the project

Open `ZeroHour.uproject` with Unreal Engine 5.4. Add any required project content locally only when you have the rights to use and redistribute it.
